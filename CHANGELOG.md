# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow Semantic Versioning where practical.

## [0.1.0-rc.1] - 2026-08-28

### Added

- Release-candidate metadata and MIT licensing for the experimental Linux application.
- Offline repository checks, deterministic unit harness, and HTTP authentication/header/shutdown integration smoke.
- Public security policy, contribution guidance, code of conduct, architecture, configuration, testing, and troubleshooting documentation.
- GitHub Actions CI, dependency audit, secret scanning, Dependabot, and focused issue/PR templates.

### Changed

- Documented the distinction between offline, system, live, and deployment checks.
- Documented Tailscale as experimental transport exposure rather than authentication.
